# Security Policy

## Official Website

The official BanterBird website is:

https://banterbird.app

No other domain should be considered an official source for BanterBird unless it is explicitly linked from https://banterbird.app.

## Reporting Security Issues

If you discover a security vulnerability affecting BanterBird, please report it responsibly.

Do not disclose vulnerabilities publicly until they have been reviewed.

## Brand Notice

BanterBird is not affiliated with any website, application, company, or service using the "BanterBird" name under any domain other than:

https://banterbird.app

If you encounter another website using the BanterBird name, it should not be assumed to be associated with the official BanterBird platform.

## Scope

This repository primarily contains public information about the BanterBird project. Security reports related to the BanterBird platform should reference the official website:

https://banterbird.app
