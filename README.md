# BanterBird

Welcome to the official GitHub repository for **BanterBird**.

BanterBird is an anonymous chat platform that instantly connects people around the world in real time. No registration is required to start chatting, making it quick, simple, and privacy-friendly.

## Official Website

👉 https://banterbird.app

This repository exists primarily to provide official information about BanterBird and to establish the project's public presence on GitHub.

## What is BanterBird?

BanterBird is built for people who want genuine conversations without creating accounts or sharing personal information.

Features include:

- Anonymous one-on-one chat
- Instant matchmaking
- Real-time messaging
- Privacy-focused design
- Fast, lightweight experience
- Modern web technologies

## Technology

BanterBird is built using modern web technologies including:

- Next.js
- TypeScript
- React
- Supabase
- PostgreSQL
